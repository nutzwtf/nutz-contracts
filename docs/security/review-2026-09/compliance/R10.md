## R10 — Circuit breaker: instant disable, timelocked enable, disabled share paid as USDG

> "(c) **circuit breaker** — `Converter.legDisabled[stock]` (`disableLeg`: 2-of-3 signers, instant; `proposeLegEnable` / `executeLegEnable`: 48h timelock to re-enable) reroutes that stock's share of the Stash slice into USDG at the next sweep, and the indexer allocates it as Cash"
> — docs/spec/engineering-spec.md §6, "Threat: issuer blocklist / pause on a Stock Token"

> "`disableLeg(uint8 stock, sig1, sig2)` — the Circuit breaker (§6), instant 2-of-3 over `DisableLeg(uint8 stock,uint256 nonce)`, `stock` in `0..3`. `proposeLegEnable(uint8 stock, sig1, sig2)` — 2-of-3 over `EnableLeg(uint8 stock,uint256 nonce)`, scheduled through the shared 48h timelock; `executeLegEnable(uint8 stock)` by anyone once ready (7-day TTL, cancellable with `Signers.cancel`)."
> — docs/spec/engineering-spec.md §2.2

> "6. USDG→{SPY, NVDA, MU, SPCX}, `perStock` each through `routes[2..5]`, each isolated in try/catch and honouring the Circuit breaker: a disabled or failed Leg emits `LegSkipped(leg, reason)` (`"disabled"`, or the Venue's revert data) and its `perStock` joins Cash."
> — docs/spec/engineering-spec.md §2.2 step 6

**Verdict:** implemented · confidence: high

**What this demands of an implementation:** (1) `disableLeg` flips `legDisabled[stock]` in the same transaction given two distinct Signer signatures, no delay; (2) re-enabling needs two signatures *and* a 48h wait, executable by anyone within a bounded window, cancellable; (3) while the flag is set, the Sweep does not swap that stock and its `perStock` USDG is delivered to the Distributor as USDG (index 4); (4) the same holds for the Acorn conversion.

**Where enforcement lives:**

```solidity
// src/NutzConverter.sol:L272-L278   (1)
function disableLeg(uint8 stock, bytes calldata sig1, bytes calldata sig2) external {
    _checkLeg(stock);
    if (legDisabled[stock]) revert LegAlreadyDisabled(stock);
    _require2of3(keccak256(abi.encode(DISABLE_LEG_TYPEHASH, stock, nonce)), sig1, sig2);
    legDisabled[stock] = true;
    emit LegDisabled(stock);
}

// src/NutzConverter.sol:L282-L295   (2)
function proposeLegEnable(uint8 stock, bytes calldata sig1, bytes calldata sig2) external {
    _checkDisabled(stock);
    _require2of3(keccak256(abi.encode(ENABLE_LEG_TYPEHASH, stock, nonce)), sig1, sig2);
    _schedule(keccak256(abi.encode(ENABLE_LEG_TYPEHASH, stock)));
}
function executeLegEnable(uint8 stock) external {
    _checkLeg(stock);
    _consume(keccak256(abi.encode(ENABLE_LEG_TYPEHASH, stock)));
    _checkDisabled(stock);
    legDisabled[stock] = false;
    emit LegEnabled(stock);
}

// src/NutzConverter.sol:L481-L486   (3)(4) the skip
if (legDisabled[stock]) {
    emit LegSkipped(leg, "disabled");
    return (ok, out);          // ok == false, out == 0
}

(bool bought, uint256 stockOut) = _buyStock(i, routes[FIRST_STOCK_LEG + i], perStock);
if (bought) amounts[i] = stockOut;
```

- (1) `_require2of3` (Signers L121-L129): recovers two addresses over the EIP-712 digest, rejects `a == b` (`SameSigner`), requires both in `signers` (L131-L133), consumes the global `nonce`. No `_schedule`, no timestamp: the write at L276 is in the same call. `_checkLeg` (L297-L299) bounds `stock` to `0..3` (`STOCK_LEGS = 4`, L97).
- (2) `_schedule` (Signers L98-L103) stores `readyAt[id] = block.timestamp + TIMELOCK` with `TIMELOCK = 48 hours` (L30), and rejects a duplicate (`AlreadyScheduled`). `_consume` (L106-L117) reverts `NotReady` before `readyAt`, `Expired` after `readyAt + PROPOSAL_TTL` (`7 days`, L32), then deletes the entry. `executeLegEnable` has no access modifier ("by anyone") and re-checks the flag at L292 after consuming. `cancel` (Signers L83-L89) deletes any scheduled id under 2-of-3. The Converter's and Distributor's timelocks are separate contracts' storage; "shared" in the document means the shared `Signers` base.
- (3) In `sweep`, `_buyStock` returns `(false, 0)` for a disabled stock without calling `_runLeg`, so no approval is granted and no Venue is touched; `cashUsdg += perStock` (L340) puts the share into `amounts[4]` (L342). `_fundEpoch` (L493-L498) approves `amounts[4] + acornUsdg` of USDG and calls `notifyEpochFunding`, which records `funded[4] += amounts[4]` (Distributor L209-L211) and pulls `amounts[USDG] + acornUsdg` of USDG (L217-L218). The USDG is in the Converter because it was never spent (the stock swap was skipped).
- (4) In `convertAcorn`, the same `_buyStock` is used (L536); the skipped share goes to `usdgLeft` (L538) → `amounts[4]` (L540) → `_fundDraw` (L547-L551) → `notifyDrawFunding`, which records and pulls all five amounts (Distributor L241-L247), USDG at index 4.

**Paths walked:**
- `disableLeg` with `stock ≥ 4` → `InvalidLeg` (L298). With an already-disabled stock → `LegAlreadyDisabled` (L274). With one valid and one invalid signature, or the same signer twice → revert in `_require2of3`. Two distinct Signers → flag set at once. ✓
- `proposeLegEnable` on an enabled stock → `LegNotDisabled` (L303). Twice for the same stock while scheduled → `AlreadyScheduled` (Signers L99). ✓
- `executeLegEnable` before 48h → `NotReady`; after 48h + 7 days → `Expired`; with nothing scheduled → `NotScheduled`; after `cancel` → `NotScheduled` (entry deleted at L87). After a valid consume, if the stock is somehow no longer disabled → `LegNotDisabled` at L292 (no path re-enables other than this function, so this branch is defensive). ✓
- Sweep with stock `i` disabled: the loop at L337 calls `_buyStock` for every `i`; the disabled one emits `LegSkipped(leg, "disabled")` and contributes `perStock` to Cash; the other three still swap. ✓
- Sweep with stock `i` disabled *and* its Route malformed: `_buyStock` returns before `_runLeg`, so the Route is never validated. A bad Route on a disabled Leg does not revert. Consistent with "reroutes … at the next sweep" (the Keeper need not supply a valid Route for a disabled Leg). —
- Acorn with stock `i` disabled: same skip; the share stays USDG in the Draw's funding. ✓
- Timelock id collision: the enable id is `keccak256(abi.encode(ENABLE_LEG_TYPEHASH, stock))` (L285/L291); the rotation id is `keccak256(abi.encode(ROTATE_TYPEHASH, from, to))` (Signers L70); different typehash constants, so the shared `readyAt` mapping cannot confuse them. ✓
